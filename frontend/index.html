                    Why keyboard access is needed
                    
WIS reads key state directly so the same in-app shortcut works across Linux desktops. It does not consume keypresses; choose a shortcut that does not conflict with another action. If access is denied, grant your account input-device access and restart WIS.

                    
sudo usermod -aG input "$USER"

                    
Then sign out and back in. Membership in the input group gives programs running as your account read/write access to input devices.
