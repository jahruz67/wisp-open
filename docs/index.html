Questions

Frequently asked questions.

Is Wisp really 100% free and open source?
Yes. Wisp (WIS Free V3) is distributed under the permissive MIT License. There are no subscriptions, no locked tiers, no accounts required, and no hidden telemetry.
Do I need an API key to use Wisp?
No. You can download any of the offline models directly within Settings (such as local GPU or CPU models) and run 100% offline with zero external network requests. If you want ultra-fast cloud inference, you can optionally paste a free cloud API key.
How does direct typing work in any application?
Wisp injects keystrokes natively into whichever window had focus right before you released the hotkey. On Linux, it uses a persistent direct-typing service and /dev/uinput; on Windows, it uses Win32 input events; on macOS, it uses accessibility paste hooks. You never need to switch apps or press Paste.
Can I customize the recording shortcut?
Yes. While the default is Ctrl+Super (Ctrl+Win on Windows, Ctrl+Cmd on macOS), you can click Record in the Wisp Settings window and press any shortcut combination you prefer.
Does offline transcription support GPU acceleration?
Yes. Packages include an offline Vulkan backend on Windows and Linux, supporting NVIDIA, AMD, and Intel GPUs out of the box without requiring manual driver compilation. On Apple Silicon macOS, Metal acceleration is used.
